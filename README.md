# Covid-Antigen-Diagnostic-System
A two-stage deep learning system for automated COVID-19 antigen test diagnostics. Stage 1 uses a YOLOv5-based model to detect and crop the test kit from an image. Stage 2 uses an advanced Swin Transformer V2 model to classify the cropped image as POSITIVE, NEGATIVE, or INVALID. This project was developed as part of a deep learning course.
